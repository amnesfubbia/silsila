POHON KELUARGA — VERSI ONLINE MVP

BERKAS
- index.html: demo lokal terdahulu.
- online.html: MVP yang dapat dikonfigurasi untuk Supabase; akun, buat ruang keluarga, daftar profil anggota, cerita keluarga, dan pembacaan data online.
- supabase_schema.sql: struktur database dan RLS awal.
- SETUP_ONLINE.txt: langkah setup.

PENTING
Versi online belum langsung aktif karena membutuhkan proyek Supabase milik pengguna dan SQL yang dijalankan di proyek tersebut. Fitur undangan anggota dan hubungan ayah/ibu yang disetujui belum aktif pada MVP ini. Jangan gunakan service_role key di browser.
